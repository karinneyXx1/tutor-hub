# Как помочь проекту

Спасибо, что заглянули!

## Сообщить о проблеме

Откройте Issue и опишите:
- **ошибку (bug):** что делали, что ожидали, что получили; если можно, шаги для воспроизведения;
- **пожелание (feature):** какой возможности не хватает и зачем она нужна;
- **вопрос (task):** что именно непонятно.

Issues автоматически размечаются ботом. Если описание слишком общее, Issue получит метку `needs-triage`, и его посмотрит человек.

## Предложить изменение

1. Создайте ветку от `main`.
2. Внесите изменения и добавьте тесты.
3. Проверьте локально: `make test`.
4. Откройте pull request. Бот сделает AI-ревью, тесты запустятся в GitHub Actions.
