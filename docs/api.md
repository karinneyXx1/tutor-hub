# API

Все эндпоинты, кроме регистрации, входа и `/api/health`, требуют заголовок `Authorization: Bearer <token>`. Токен выдаёт `POST /api/auth/login`.

Интерактивная документация доступна на `/docs` при запущенном сервере.

## Вход

| Метод | Путь | Кто | Что делает |
|---|---|---|---|
| POST | `/api/auth/register` | все | регистрация: `email`, `name`, `password` (от 8 символов), `role` (`tutor` / `student`) |
| POST | `/api/auth/login` | все | вход: `email`, `password` → `token`, `user` |
| POST | `/api/auth/logout` | вошедший | выход, токен перестаёт работать |
| GET | `/api/auth/me` | вошедший | текущий пользователь |

## Ученики

| Метод | Путь | Кто | Что делает |
|---|---|---|---|
| GET | `/api/students` | репетитор | список своих учеников |
| POST | `/api/students` | репетитор | добавить зарегистрированного ученика по `email` |

## Домашние задания

| Метод | Путь | Кто | Что делает |
|---|---|---|---|
| POST | `/api/homework` | репетитор | выдать ДЗ: `student_id`, `title`, `description`, `due_date` (не в прошлом) |
| GET | `/api/homework?status=` | все | свои ДЗ: у репетитора выданные, у ученика полученные; фильтр по статусу |
| GET | `/api/homework/{id}` | репетитор или ученик этого ДЗ | одно ДЗ |
| POST | `/api/homework/{id}/submit` | ученик | сдать: `answer`; можно из статусов `assigned` и `returned` |
| POST | `/api/homework/{id}/review` | репетитор | проверить: `grade` 1–5, `feedback`; только из `submitted` |
| POST | `/api/homework/{id}/return` | репетитор | вернуть на доработку: `feedback`; только из `submitted` |

## Расписание

| Метод | Путь | Кто | Что делает |
|---|---|---|---|
| POST | `/api/lessons` | репетитор | урок: `student_id`, `starts_at`, `duration_min` (15–240), `topic` |
| GET | `/api/lessons` | все | свои уроки по времени |
| DELETE | `/api/lessons/{id}` | репетитор | удалить свой урок |

## Коды ошибок

| Код | Когда |
|---|---|
| 401 | нет токена или он недействителен |
| 403 | действие недоступно для этой роли |
| 404 | объект не найден или принадлежит другому пользователю |
| 409 | email уже занят; действие недоступно в текущем статусе ДЗ |
| 422 | ошибка валидации: пустое поле, срок в прошлом, оценка вне 1–5 и т.п. |
