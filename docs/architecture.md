# Архитектура

## Структура

```
backend/
├── app/
│   ├── main.py        # приложение FastAPI, CORS, подключение роутеров
│   ├── db.py          # соединение с SQLite и схема таблиц
│   ├── security.py    # хеширование паролей (PBKDF2) и токены сессий
│   ├── deps.py        # текущий пользователь, проверка роли и принадлежности ученика
│   ├── schemas.py     # модели запросов и ответов (pydantic), валидация
│   └── routers/
│       ├── auth.py      # регистрация, вход, выход
│       ├── students.py  # ученики репетитора
│       ├── homework.py  # ДЗ и переходы статусов
│       └── lessons.py   # расписание
└── tests/             # pytest, у каждого теста своя временная база
```

## Данные

| Таблица | Содержимое |
|---|---|
| `users` | пользователи с ролью `tutor` или `student` |
| `sessions` | токены входа |
| `tutor_students` | какие ученики у какого репетитора |
| `homework` | ДЗ: статус, ответ ученика, оценка и комментарий |
| `lessons` | уроки в расписании |

Схема создаётся при старте приложения (`init_db`).

## Правила доступа

- Репетитор работает только со своими учениками (`ensure_own_student`).
- ДЗ и уроки видят только их репетитор и ученик; чужим возвращается 404, чтобы не раскрывать существование объекта.
- Переходы статусов ДЗ проверяются на сервере: недопустимый переход возвращает 409.

## Автоматизация вокруг репозитория

Репозиторий обслуживают сценарии n8n:
- AI-ревью pull request-ов;
- классификация Issues по типам (`bug` / `task` / `feature`) с эскалацией в `needs-triage`;
- еженедельная статистика по Issues и PR на почту.
