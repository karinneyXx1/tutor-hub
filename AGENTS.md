# AGENTS.md

Правила для AI-агентов, которые меняют код этого репозитория.

## Проект

«Код-репетитор»: API на FastAPI + SQLite в `backend/`. Описание эндпоинтов — [docs/api.md](docs/api.md), устройство — [docs/architecture.md](docs/architecture.md).

## Команды

```bash
make install   # зависимости
make test      # тесты (обязательно перед завершением работы)
make run       # сервер на :8000
```

## Правила

- Делайте минимальное изменение, которое решает задачу; не трогайте несвязанный код.
- Любое изменение поведения сопровождайте тестом в `backend/tests/`.
- SQL пишите только с параметрами (`?`), никогда не подставляйте значения через f-строки.
- Проверка доступа обязательна: репетитор работает только со своими учениками, ДЗ и уроки видят только их участники.
- Переходы статусов ДЗ проверяются на сервере (см. `routers/homework.py`).
- Не добавляйте секреты, токены и базы данных в репозиторий.
- Обновляйте `docs/api.md`, если меняется API.

## Готово, если

- `make test` проходит;
- новое поведение покрыто тестами;
- документация соответствует коду.
